Two tracks and a side quest
Pick one track. Every project moves money through Stripe test mode.
TRACK 01
Agents that spend
Build an agent that pays, issues or moves funds under a policy, and can explain every pound.
YOUR AGENT MUST
Money moves in Stripe test mode in your demo video.
The agent enforces a written policy: limits, approvals, allowed merchants or counterparties.
It answers "why did you pay this?" by pointing to the rule and the evidence.
IDEAS
A bill-paying agent that stays within approval limits
A buying agent with a capped virtual card
A refunds or disputes agent
Contractor payouts
WITH COGNEE
Keep the spending policy and its history in Cognee memory, so the agent can name the clause that authorised each payment and recall why it acted.
TRACK 02
Agents that collect
Build an agent that invoices, meters or sells, without a human raising the bill.
YOUR AGENT MUST
Something in the real world triggers the agent: an email, a contract, usage logs, a conversation.
It creates a real bill in Stripe test mode: an invoice, payment link, checkout session, meter event or subscription.
No human raises the bill.
IDEAS
Usage logs turned into meter events, then an invoice
An agent that turns a contract into invoices
A collections agent that remembers each customer's promises and disputes
An agent that sells to another agent
WITH COGNEE
Give sales, billing and collections agents one shared customer memory.
SIDE QUEST
Best use of Cognee memory
Open to every team that builds with Cognee, in either track. The panel looks at how central Cognee memory is to the agent working, and how well the agent explains its actions from that memory.
